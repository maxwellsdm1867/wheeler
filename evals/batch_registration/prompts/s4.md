## Method (strategy 4: write a manifest, validate it, then register)

1. Use the Write tool to create `provenance.yaml` in the project directory in Wheeler's manifest shape:

```yaml
nodes:                     # non-file nodes: execution and findings
  - alias: "@exec"
    type: execution
    kind: script_run
    description: "..."
  - alias: "@f1"
    type: finding
    description: "..."     # finding text verbatim
    confidence: 0.8
artifacts:                 # files on disk, relative to the project directory
  - alias: "@s1"
    path: scripts/load_epochs.py
    title: "..."
    description: "..."
edges:                     # endpoints are @aliases or literal node ids
  - ["@s1", "WAS_GENERATED_BY", "@exec"]
  - ["@f1", "APPEARS_IN", "@fig01"]
  - ["@f1", "RELEVANT_TO", "{QUESTION_ID}"]
  - ["@exec", "USED", "{DATASET_ID}"]
```

Every node and artifact gets a unique `@alias`. Edge endpoints are aliases or the literal ids {QUESTION_ID} and {DATASET_ID}.

2. Validate first, with one Bash call:

```
{PYTHON} -m wheeler.tools.cli integrate register provenance.yaml --dry-run
```

It writes nothing and prints structural errors plus any literal node ids that do not exist in the graph. Fix everything it reports in one edit of the manifest (at most one fix-and-revalidate cycle).

3. Then register for real with exactly one Bash call:

```
{PYTHON} -m wheeler.tools.cli integrate register provenance.yaml
```

Do NOT use the MCP mutation tools for individual nodes or edges.
