## Method (strategy 3: write a manifest, register it with one CLI call)

1. Use the Write tool to create `provenance.yaml` in the project directory in Wheeler's manifest shape:

```yaml
nodes:                     # non-file nodes: execution and findings
  - alias: "@exec"
    type: execution
    kind: script_run
    description: "..."
  - alias: "@f1"
    type: finding
    description: "..."     # finding text verbatim
    confidence: 0.8
artifacts:                 # files on disk, relative to the project directory
  - alias: "@s1"
    path: scripts/load_epochs.py
    title: "..."
    description: "..."
edges:                     # endpoints are @aliases or literal node ids
  - ["@s1", "WAS_GENERATED_BY", "@exec"]
  - ["@f1", "APPEARS_IN", "@fig01"]
  - ["@f1", "RELEVANT_TO", "{QUESTION_ID}"]
  - ["@exec", "USED", "{DATASET_ID}"]
```

Every node and artifact gets a unique `@alias`. Edge endpoints are aliases or the literal ids {QUESTION_ID} and {DATASET_ID}.

2. Register it with exactly one Bash call:

```
{PYTHON} -m wheeler.tools.cli integrate register provenance.yaml
```

Read the JSON it prints. If it reports errors, fix the manifest and re-run once. Do NOT use the MCP mutation tools for individual nodes or edges.
